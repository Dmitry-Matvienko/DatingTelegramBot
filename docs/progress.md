## Сейчас
- **Фаза**: Исправление логики **сохранения клавиатуры при поиске и взаимной симметрии подбора анкет**:
  1. **Исправление сохранения клавиатуры при обычном поиске**:
     - Введен статус `UserState.Searching_ViewingIncoming` для четкого разграничения режима просмотра входящей симпатии (ответ на оценку) от обычного поиска (`Searching`).
     - При обычном поиске анкет выставление любой оценки (включая 6+) больше не прерывает поиск и не переключает клавиатуру на Главное меню; поиск плавно продолжается с сохранением цифровой клавиатуры `1️⃣`..`🔟`.
     - Возврат в Главное меню с клавиатурой `[🔍 Искать анкеты] [👤 Мой профиль]` срабатывает только при взаимной симпатии в ответ на входящую карточку (`view_rater`).
  2. **Исправление взаимной видимости анкет (на примере Настя 15 / Влад 22)**:
     - В `UserProfileRepository.BuildBaseCandidateQuery` устранена избыточная блокировка `&& p.Age < 18` для несовершеннолетних пользователей, из-за которой взрослые без возрастных фильтров видели несовершеннолетних, но несовершеннолетние не видели их в ответ.
     - Исправлено сравнение меток времени в выборке `CreatedAt > cycleStartedAt` (вместо `>=`), предотвратившее отсечение единственного кандидата в цикле при совпадении миллисекунд.
  3. **Тестирование и спецификации**:
     - Обновлены спецификации `matchmaking_scoring.md` и `search_and_ratings.md`.
     - Добавлены тесты для симметричной выборки и непрерывного поиска (все 380 тестов решения: 100% green, 0 failures).
- **Далее**: Ожидание следующих задач от пользователя.
